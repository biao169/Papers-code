# Papers-code
All the publicly available codes for one's own research papers or the codes for reproducing the results of others' papers


Please note that in the currently disclosed code, each folder represents a method. It includes `model.py` and `run_xxx.py` (or `train_xxx.py`).

> `model.py` contains the detailed construction code and loss calculation methods of the model.

> `run_xxx.py` (or `train_xxx.py`) is the startup file, which is used for training and testing this method. It includes important configuration parameters such as learning rate, regularization coefficient, and dataset reading configuration.

Additionally, the data set reading architecture and training architecture that go along with it have not yet been finalized, so they are not yet made public at present. Please look forward to the subsequent full public code.
---
Therefore, when using it, please pay attention to modifying the import path of the corresponding package.
